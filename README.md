# JobPilot Agent

همراه هوشمند کاریابی برای مسیر **Junior Frontend** — مسابقه buildX (مسئله ۲)

## قابلیت‌های اصلی
- ثبت‌نام و ورود
- پروفایل و ساخت رزومه سوال‌به‌سوال (ذخیره در دیتابیس)
- پیشنهاد آگهی با امتیاز تناسب و توضیح علت
- بازخورد کاربر و اصلاح جست‌وجو
- مسیر درخواست آماده (کاور لتر + چک‌لیست)
- تمرین مصاحبه با ارزیابی پاسخ
- نتیجه نهایی و شانس استخدام تخمینی

## اجرای محلی
```bash
npm install
npx prisma generate
npx prisma db push
npm run dev
```

باز کردن: http://localhost:3000

## مستندات تحویل مسابقه
همه در پوشه `docs/submission/`:
- `01_TECHNICAL_DOCS.md` — فنی و زیرساخت
- `02_BUSINESS_PLAN.md` — بیزینس پلن
- `03_PITCH.md` — پیچ
- `04_VIDEO_LINK.txt` — لینک ویدیو
- `05_DEPLOY_AND_CHECKLIST.md` — دیپلوی و چک‌لیست
- `00_PRODUCT_LINK.txt` — لینک محصول آنلاین
