## برنامه تست کارکردی (Functional Test Plan)

### A. تست‌های پذیرش اصلی (باید همه Pass شوند)

1. **ثبت‌نام و ورود**
   - کاربر جدید با ایمیل معتبر ثبت‌نام کند
   - با همان اطلاعات وارد شود
   - Session بعد از رفرش باقی بماند

2. **جریان ایجنت کامل**
   - کاربر بدون پروفایل شروع کند → ایجنت سوال بپرسد
   - بعد از ۳–۵ پیام، ایجنت حداقل ۳ آگهی با توضیح تناسب نشان دهد
   - کاربر بازخورد منفی بدهد → لیست یا رزومه تغییر کند
   - کاربر بتواند نتیجه نهایی (رزومه + لیست) را ببیند/دانلود کند

3. **صحت محتوا**
   - توضیح تناسب باید منطقی و بر اساس مهارت‌های واقعی کاربر باشد
   - رزومه خروجی باید ساختار استاندارد داشته باشد (خلاصه، مهارت‌ها، تجربه، تحصیلات)

4. **پایداری**
   - بعد از بستن مرورگر و ورود مجدد، state قبلی حفظ شود
   - خطاهای LLM gracefully handle شوند

### B. چک‌لیست تست دستی روزانه
- [ ] ثبت‌نام
- [ ] ورود
- [ ] ساخت پروفایل
- [ ] شروع چت با ایجنت
- [ ] دریافت پیشنهاد
- [ ] ارسال بازخورد
- [ ] مشاهده تغییر
- [ ] دریافت بسته نهایی
- [ ] موبایل ریسپانسیو
- [ ] لاگ هزینه نمایش داده می‌شود

### C. تست‌های خودکار (از روز ۳ به بعد)
- pytest برای Nodeهای LangGraph
- Playwright برای جریان End-to-End در محیط staging

## معیار موفقیت نهایی
محصول روی لینک عمومی:
- ثبت‌نام → ورود → گفتگو → پیشنهاد → بازخورد → نتیجه
بدون هیچ دخالت دستی تیم، کار کند و در ویدیوی ۵ دقیقه‌ای قابل نمایش باشد.
