# راهنمای تست نسخه تقویت‌شده

## اجرا
```bash
npm run dev
```

## جریان کامل تست

1. ورود به حساب
2. تکمیل پروفایل (مهارت + سطح)
3. رفتن به چت
4. تست دکمه‌های سریع:
   - پیشنهاد آگهی → لیست با امتیاز تناسب
   - بهبود رزومه → بررسی رزومه + شانس استخدام + پیشنهاد خلاصه
   - فقط ریموت → اصلاح لیست
   - نتیجه نهایی → بسته نهایی با شانس استخدام

## موارد جدید مطابق صورت‌مسئله
- ایجنت ترجیحات و سوابق را می‌شناسد
- علت تناسب/عدم‌تناسب را توضیح می‌دهد
- با بازخورد جست‌وجو را اصلاح می‌کند
- رزومه را بررسی و پیشنهاد بهبود می‌دهد
- شانس استخدام تخمینی محاسبه می‌کند
