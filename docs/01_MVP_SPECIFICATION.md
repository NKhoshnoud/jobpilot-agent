# JobPilot Agent — MVP Specification
**مسابقه buildX | مسئله ۲ | نسخه نهایی دامنه**

## ۱. هدف محصول
ساخت یک همراه ایجنتیک کاریابی که کارجو (تمرکز: Junior Frontend) را از سردرگمی میان آگهی‌های نامرتبط و نسخه‌های مختلف رزومه نجات دهد.  
ایجنت باید ترجیحات و سوابق واقعی فرد را بشناسد، علت تناسب یا عدم تناسب هر فرصت را توضیح دهد و با بازخورد کاربر، جست‌وجو و رزومه را اصلاح کند.

## ۲. جریان اصلی End-to-End (باید ۱۰۰٪ کار کند)

| مرحله | عمل کاربر | عمل سیستم / ایجنت | Acceptance Criteria |
|-------|-----------|-------------------|---------------------|
| 1 | ثبت‌نام با ایمیل + رمز | ساخت حساب، هدایت به داشبورد | کاربر می‌تواند ثبت‌نام کند و وارد شود |
| 2 | ورود | احراز هویت و نمایش داشبورد | Session پایدار |
| 3 | ساخت/آپلود پروفایل یا رزومه | ذخیره اطلاعات پایه | پروفایل ذخیره و قابل ویرایش است |
| 4 | شروع گفتگو با ایجنت | ایجنت سوالات هدفمند می‌پرسد (مهارت‌ها، سطح، ترجیحات، حقوق، نوع قرارداد، شهر/ریموت) | ایجنت state کاربر را به‌روز می‌کند |
| 5 | ایجنت پیشنهاد آگهی می‌دهد | برای هر آگهی توضیح تناسب/عدم‌تناسب می‌نویسد | حداقل ۳ آگهی با توضیح واضح |
| 6 | کاربر بازخورد می‌دهد | ایجنت جست‌وجو یا رزومه را اصلاح می‌کند | تغییرات قابل مشاهده است |
| 7 | دریافت نتیجه نهایی | رزومه استاندارد + لیست نهایی آگهی‌ها | کاربر می‌تواند دانلود یا کپی کند |

## ۳. محدوده مجاز (In Scope)
- مسیر شغلی: **Junior Frontend Developer** (React/Next.js)
- احراز هویت ساده (Credentials)
- گفتگوی چندمرحله‌ای با ایجنت (LangGraph)
- ساخت و بهبود رزومه بر اساس استانداردهای رایج
- فیلتر و رتبه‌بندی آگهی‌ها با توضیح علت
- حلقه بازخورد کاربر → اصلاح
- رابط وب کامل (نه CLI)

## ۴. خارج از محدوده (Out of Scope) — طبق دستورالعمل مسابقه
- فراموشی رمز عبور
- پرداخت و اشتراک واقعی
- اتصال زنده به LinkedIn / Jobinja / Telegram (از داده شبیه‌سازی‌شده + چند منبع عمومی استفاده می‌شود)
- پشتیبانی از همه مسیرهای شغلی
- نوتیفیکیشن ایمیل/پیامک
- پنل ادمین پیچیده
- استفاده از سایت‌ساز، ایجنت‌ساز یا n8n

## ۵. معیارهای پذیرش محصول (طبق قوانین مسابقه)
- محصول آنلاین و قابل استفاده بدون دخالت تیم سازنده
- کاربر بتواند ثبت‌نام → ورود → ورودی → نتیجه کامل را طی کند
- قلب ایجنتیک (نه قابلیت فرعی)
- ویدیوی ۵ دقیقه‌ای مسیر واقعی را نشان دهد
- مستندات فنی، بیزینس‌پلن و پیچ کامل

## ۶. داده‌های اولیه برای تست
- ۱۰–۱۵ آگهی شبیه‌سازی‌شده Junior Frontend با سطوح مختلف تناسب
- ۳ پروفایل نمونه کارجو با مهارت‌های متفاوت
